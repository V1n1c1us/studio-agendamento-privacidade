# Política de Privacidade e Termos de Uso — Studio Karla Schlichting

Política de privacidade (LGPD, Lei nº 13.709/2018) e termos de uso do agendamento online do studio,
publicada pelo GitHub Pages:

- Política de Privacidade: **https://v1n1c1us.github.io/studio-agendamento-privacidade/**
- Termos de Uso: **https://v1n1c1us.github.io/studio-agendamento-privacidade/termos/**

- A política fica em `index.html` e os termos em `termos/index.html` (páginas únicas, sem dependências).
- Mudou o que o sistema coleta ou com quem compartilha (`studio-agendamento-api`)? Atualize a política (e os termos, se
  mudarem prazos ou regras do agendamento) e a data de vigência no topo e no rodapé.
- Este repositório é público só para hospedar essas páginas. Não coloque aqui código, dados ou segredos.
