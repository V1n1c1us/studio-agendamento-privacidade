# Política de Privacidade — Studio Karla Schlichting

Política de privacidade do agendamento online do studio, de acordo com a LGPD (Lei nº 13.709/2018),
publicada pelo GitHub Pages:

**https://v1n1c1us.github.io/studio-agendamento-privacidade/**

- O texto fica em `index.html` (página única, sem dependências).
- Mudou o que o sistema coleta ou com quem compartilha (`studio-agendamento-api`)? Atualize a política e
  a data de vigência no topo e no rodapé.
- Este repositório é público só para hospedar a política. Não coloque aqui código, dados ou segredos.
